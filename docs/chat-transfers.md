# Перетаскивание между чатами

Владелец системы может перетащить полученный файл из рабочего чата в Codex и обратно. Файл копируется в черновик назначения; исходное сообщение сохраняется. Отправка выполняется после обычного нажатия «Отправить». Для обсуждения задачи используется тот же загрузчик, поэтому файл попадает в выбранное обсуждение.

Карточка задачи из общего чата, списка задач или открытой задачи переносится в Codex ссылкой на оригинал (`/?teamChat=<workspaceId>&task=<taskId>`). Ссылка отображается отдельным удаляемым элементом черновика. В запрос передаются исходная ссылка и идентификаторы, без устаревшей копии описания. `codex/context.md` задаёт чтение актуальной задачи, всех страниц переписки и необходимых файлов через `index12_chat_*`; облачный и desktop Codex используют этот контекст и существующие инструменты чтения.

При создании рабочей задачи слева внизу поля доступны две быстрые команды: «Оплатить счёт» и «Выставить счёт». Выбранная команда отображается чипом перед текстом, сохраняется обычным префиксом описания (`Оплатить счёт: …` / `Выставить счёт: …`) и доходит до календаря и MCP без отдельной копии. Backspace в начале текста удаляет чип целиком, оставляя описание; повторный выбор заменяет направление без дублей. Кнопки остаются видны при наборе.

Если нажать «Отправить» в Codex с прикреплённой задачей и пустым текстом, клиент просит прочитать оригинал, нужную переписку и вложения и ответить по содержанию. Команды в начале задачи явно выбирают соответствующую цепочку по `index12_invoice_rules`. Остальные задачи остаются обычными: без финансовой команды или отдельного явного поручения владельца счета не оформляются, даже при наличии PDF. Само перетаскивание ничего не отправляет. Собственный текст владельца сохраняется: «проверь» не заменяется финансовым поручением.

В редакторе банковских счетов администратор может отметить несколько счетов «По умолчанию». Для расходов выбор: компания-покупатель → отмеченные счета → порядок строк. Остаток не используется. Кассы и исключённые счета не участвуют; перевод в эти группы снимает отметку. Пока отметок нет вообще, допускается только однозначный BCCUU соответствующей компании. Настройки сохраняются обычным сохранением редактора.

Передача работает между окнами одной страницы, только в текущей авторизованной сессии владельца и одной рабочей области. В DataTransfer находится одноразовый непрозрачный токен; внешние URL не используются для загрузки файлов. Источник читает файл своим транспортом с проверкой прав. Смена пользователя, рабочей области, закрытие источника или истечение токена отменяют передачу. Лимиты вложений совпадают с обычной загрузкой: пять файлов, 10 МБ на файл, 25 МБ суммарно. Чтение файла при передаче не создаёт отметку просмотра.

Проверки: `npm run test:task-invoice-commands` — выбор, замена, Backspace/мобильный beforeinput, сохранение префикса и текста без обрезки, обе темы, ширины 320/390/1280, скрепка и микрофон в одной строке. Входит в `test:task-creation` и `test:chat-ui`. `npm run test:chat-transfer` — Chromium/WebKit, мышь/касания, обе темы, файлы в обе стороны, сохранение черновика, обычные задачи без автоматического оформления счетов, удаление и повторное добавление ссылки, отсутствие автоматической отправки. `tests/chat-transfer.test.mjs` проверяет токены, истечение и изоляцию сессий. Обязательная регрессия чата — `npm run test:chat-ui`. Все данные локальные и синтетические, скриншоты не используются.

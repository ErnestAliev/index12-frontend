# Чат и задачи

В рабочий Vue-интерфейс перенесён согласованный сценарий задач. Реальные участники и документы приходят из `/api/team-chat`; переключателя чужих профилей нет. Основная навигация: «Чат» и «Задачи». Меню содержит только «Чат», «Задачи», переключение темы и включение/выключение уведомлений.

Заявки на расходы и их связь с финансовым календарём удалены. Существующие финансовые операции не удаляются.

Проверки: `npm test`, `npm run build`. Браузерная проверка полного сценария: `INDEX12_TASK_BROWSER_FIXTURE=/path/to/temporary-fixture.json node tests/browser/team-chat-tasks.mjs`. Временное описание готовит backend интеграционный тест с тем же параметром окружения. Он использует отдельную тестовую базу, не рабочие записи.

Перед выпуском на мобильные устройства проверить настоящие клавиатуры iOS/Android в дополнение к автоматическим геометрическим проверкам (`docs/mobile-layout.md`).

Переписка общего чата и обсуждения задач использует один `TeamChatConversation` с общими `CodexComposer`, меню сообщения, диктовкой, вложениями, очередью повторной отправки, цитатами и реакциями. При входе в задачу шапка общего чата заменяется шапкой задачи. На телефоне фокус ввода и открытие клавиатуры сворачивают параметры задачи; нажатие на заголовок раскрывает их. Прокрутка следует за последним сообщением при изменении высоты, если пользователь находился внизу.

Удержание карточки или строки задачи открывает меню с удалением; прокрутка отменяет удержание. Внутри задачи удаление доступно через корзину в шапке. Автор и владелец могут удалить задачу после подтверждения. Сервер проверяет версию и в одной транзакции скрывает задачу, обложку и переписку. Повтор удаления безопасен; отправлять новые комментарии в удалённую задачу нельзя.

Дополнительная браузерная проверка: `INDEX12_TASK_BROWSER_FIXTURE=/path/to/temporary-fixture.json node tests/browser/team-chat-parity.mjs`.

Задачи чата отображаются в общем календаре текущей рабочей области через серверное представление `source=team-chat`, `sourceTaskId` и ID `chat:UUID`. Копии в `businessTasks` не создаются. Срок, время и статус читаются из исходной задачи; время срока не превращается в выдуманный час занятости. Без срока — раздел «Без даты», включая мобильный фильтр. Клик открывает карточку внутри календаря. Текст, срок, время, ответственные, вложения и статус сохраняются в исходную задачу через API чата с проверкой версии; копии не создаются. Переход к переписке — отдельная кнопка «Рабочий чат». Перенос на другой день меняет срок той же задачи. Создание, изменение и удаление вызывают обновление календаря по сокету.

Под фильтром контрагентов расположен выбор сотрудника: «Все», «Мои» (по назначению, а не авторству), конкретный участник. На телефоне фильтры доступны по иконке в шапке. В обоих фильтрах — задач и календаря — касание вне панели закрывает её без нажатия на содержимое под ней.

Проверка чипов, фильтров и календаря: `npm run test:task-calendar` (Chromium и WebKit). Серверная проверка связи задач, отсутствия копий и изоляции рабочих областей входит в `node tests/integration/team-chat.cjs` backend.

На узком экране сетка месяца показывает дату и до трёх индикаторов с количеством остальных задач. Касание выбирает день; задачи открываются из отдельного списка, отсортированного по времени. Список занимает оставшееся место, прокручивается отдельно, кнопка добавления находится в его шапке. «Без даты» переключает список на задачи без срока. В альбомной ориентации сетка и список стоят рядом.

Фильтр не содержит отдельных заголовков «Задачи», «Контрагент», «Сотрудники»: поля показывают «Все контрагенты» и «Все сотрудники», шрифт — 13px. Доступные имена полей сохранены через aria-label.

«Удалённые задачи» в шапке календаря открывают общий список удалённых обычных задач и задач чата текущей области. Восстановление проверяет версию и права, повтор безопасен. У обычных задач восстанавливаются доступные вложения и отменяется их удаление по TTL; если часть файлов уже отсутствует, пользователь видит сообщение после восстановления. Задачи чата возвращаются вместе с сообщениями, скрытыми именно при удалении задачи; отдельно удалённые сообщения не восстанавливаются. Для старых удалений без маркера используется исходная дата и автор каскадного удаления. Уже перезаписанные старой версией сведения о самостоятельном удалении сообщения восстановить нельзя.

Проверка `test:calendar-layout` дополняет сценарий задач: обычная карточка календаря, парные даты/время, шрифты, поиск/селекты в фокусе, дата удаления и непрозрачный диалог вне контекста чата. Запускается в светлой и тёмной темах, Chromium/WebKit, 320/390/1280px и включена в `test:task-calendar`.

Подзадачи создаются через «Новая подзадача» в меню вложений обсуждения или кнопку «Добавить подзадачу» в параметрах задачи. Сценарий выбора исполнителя, срочности, срока и описания общий с обычными задачами. После создания или отмены открывается исходная задача. Список прямых подзадач расположен в её параметрах, а на карточке общего чата — счётчик. Каждая подзадача имеет собственные статус и обсуждение; ссылка сверху и кнопка «Назад» возвращают к родителю. Отдельная карточка в общий чат не публикуется. DOM-проверка без изображений: `node tests/browser/team-chat-subtasks.mjs`.

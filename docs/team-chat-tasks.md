# Чат и задачи

В рабочий Vue-интерфейс перенесён согласованный сценарий задач. Реальные участники и документы приходят из `/api/team-chat`; переключателя чужих профилей нет. Основная навигация: «Чат» и «Задачи». Меню содержит только «Чат», «Задачи», переключение темы и включение/выключение уведомлений.

Заявки на расходы и их связь с финансовым календарём удалены. Существующие финансовые операции не удаляются.

Проверки: `npm test`, `npm run build`. Браузерная проверка полного сценария: `INDEX12_TASK_BROWSER_FIXTURE=/path/to/temporary-fixture.json node tests/browser/team-chat-tasks.mjs`. Временное описание готовит backend интеграционный тест с тем же параметром окружения. Он использует отдельную тестовую базу, не рабочие записи.

Перед выпуском на мобильные устройства проверить настоящие клавиатуры iOS/Android в дополнение к автоматическим геометрическим проверкам (`docs/mobile-layout.md`).

Переписка общего чата и обсуждения задач использует один `TeamChatConversation` с общими `CodexComposer`, меню сообщения, диктовкой, вложениями, очередью повторной отправки, цитатами и реакциями. При входе в задачу шапка общего чата заменяется шапкой задачи. На телефоне фокус ввода и открытие клавиатуры сворачивают параметры задачи; нажатие на заголовок раскрывает их. Прокрутка следует за последним сообщением при изменении высоты, если пользователь находился внизу.

Удержание карточки или строки задачи открывает меню с удалением; прокрутка отменяет удержание. Внутри задачи удаление доступно через корзину в шапке. Автор и владелец могут удалить задачу после подтверждения. Сервер проверяет версию и в одной транзакции скрывает задачу, обложку и переписку. Повтор удаления безопасен; отправлять новые комментарии в удалённую задачу нельзя.

Дополнительная браузерная проверка: `INDEX12_TASK_BROWSER_FIXTURE=/path/to/temporary-fixture.json node tests/browser/team-chat-parity.mjs`.
